# Bài tập tuần

Bài tập trên lớp của môn **Hệ thống Quản trị Qui trình Nghiệp vụ** (IE203.F31.CN1.CNTT).

Thư mục này **không thuộc đồ án cuối kỳ**. Khi đóng gói bản nộp đồ án (hạn 07/09/2026)
thì loại trừ toàn bộ `bai-tap-tuan/`.

## Quy ước

- Tên thư mục: `<yyyy-mm-dd>-<chu-de-khong-dau>/` — ngày nộp, không dấu, nối bằng `-`.
- File nộp đặt trong `output/`, tên theo MSSV:
  - Bài nhóm: `24730132_24730131_24730090_24730099.docx`
  - Bài cá nhân: `<MSSV>.docx`
- Đề bài và tài liệu giảng viên phát để trong `de-bai/`. File PDF bài giảng
  (`chap*.pdf`, `Buổi*.pdf`, `Practice*.pdf`) đã bị `.gitignore` chặn — giữ trên máy,
  không đẩy lên repo.
- Script sinh sơ đồ (`gen_diagram.py`) và `group.json` để ở gốc thư mục bài.
- Tiền tố commit: `bai-tap:`
